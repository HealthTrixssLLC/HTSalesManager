IMPORTANT IDENTITY CORRECTION

The implemented system is authoritative, not the old documentation examples.

Canonical production ID patterns are:

Account     = ACCT-{YYYY}-{SEQ}
Contact     = CONT-{YY}{MM}-{SEQ}
Lead        = LEAD-{SEQ}
Opportunity = OPP-{YYYY}-{SEQ}
Activity    = ACT-{YY}{MM}-{SEQ}

There is NO functional Account/Activity collision because Account uses ACCT-* and Activity uses ACT-*.

Do NOT migrate Activity IDs to ATV-* at this time.

Preserve all existing canonical production IDs.

Update all External API documentation, examples, OpenAPI schemas, validation logic, and future agent/MCP guidance to use the actual implemented ID formats.
